在阿里云服务器上搭建Hexo(Fluid主题)博客——完整流程

欢迎来到Aiden的博客，这里我将分享一些有趣的想法和经验。

一些前言

回想第一次产生自建网站或者博客的想法，是在3年前，但是由于时间和技术原因一直没有去动手实现，其实最初我也做了点简单尝试，例如结合Github的托管服务，在Github Pages上部署一个Hexo个人博客，当然这方面的教程很多且操作很简单，但由于众所周知的原因，github.io一般访问起来没有那么顺畅(魔法例外)，因此我就一直挂念着什么时候自己搭个网站跑起来，或者用自己的主机作为服务器，或者租一个云服务器，于是这篇文章得以产生。总的来说，写这篇博文是用于总结这一周的尝试和思考，并形成一个相对详细的流程总结，以便帮助有类似想法但没有相关技术经验的小伙伴顺利构建属于自己的博客空间。

一、服务器及博客框架选择

1. 服务器选型

正如前文所说，搭建个人网站可以考虑使用个人PC作为服务器，然后通过内网穿透等其他技术将搭建好的网站映射到公网，但考虑到大多数同学的电脑都另有他用，我们也不会保证个人电脑24小时开机以维持网站运行，所以租用一个云服务器似乎是更好的选择。

当前云服务器平台有很多，大一些的平台包括阿里云、腾讯云、华为云等等，推荐使用大平台租用服务器，因为大的平台相对有更好的售后保障能力，同时有较高的抗风险能力。这里博主选择阿里云(PS:因为有活动，所以36块搞了个一年的2Core-2G-3M的服务器，同时注册了一个域名，关于域名注册以及解析及备案流程后续分享)。

服务器系统选择的是纯净的Ubuntu 24.04，然后远程连接进服务器，准备开始配置环境，这里推荐直接使用官方远程连接工具，当然也可以使用Xshell等终端连接工具。

2. 网站搭建框架选择

众所周知，网站可以分为静态和动态两种，这里的静态和动态不是依据页面上是不是具备什么绚丽的动画来区分，而是以内容生成、交互方式、技术架构等方面为区分，对于静态网站来说，一般由固定的HTML页面组成，用户访问网站时，浏览器直接加载HTML页面然后到本地渲染，而对于动态网站来说，页面内容可能根据用户请求、数据库内容等实时生成，简单来说它一般带有数据库数据请求先来填充完善HTML模板，服务器脚本通常涉及了PHP、Ruby等来实现交互。

一想到建站(个人博客)，很多朋友可能想到使用宝塔面板，或者相对更纯净精简的1Panel面板，这些服务器运维面板可以很轻易的帮助我们建立起自己的网页，只需要按照引导安装相关依赖，然后找个工具例如WordPress等CMS(Content Management System)来管理网站数字内容，就轻而易举的实现了很多功能，况且WordPress目前占据全球网站工具使用比率的近30%，它不仅能帮助建立个人博客这类轻量网站，同时也适合为企业搭建商务网站，它具有很丰富的第三方插件库，尽管它有种种优点，但是对于个人博客来说其功能完备甚至到冗杂，却反而可能带来缺陷，例如加载速度慢等问题。

因此使用Hexo这类静态网站框架搭建个人博客空间似乎是更好的方式，这里又带来几种选择，例如由Go语言编写的号称最快的网页编译框架Hugo，还有Github大力支持的基于Ruby语言开发的Jekyll框架，当然还包括Javascript编写的Hexo，选择哪种看自己口味，博主这里思考再三还是选择了Hexo，一方面Hexo框架中有我特别喜欢的主题，能够省去大量的魔改时间，且Hexo社区比较活跃，技术支持也比较完备，是个不错的选择。

二、Hexo环境配置

1. Node.js安装

方法1，使用Ubuntu默认仓库安装

  • 更新本地包索引
    sudo apt update
  • 安装Node.js
    sudo apt install nodejs
  • 安装npm(Nodejs包管理器)
    sudo apt install npm
  • 验证安装
    node -v

方法2，使用NodeSource PPA安装

  • 下载特定版本的NodeSource安装脚本（以v20.x为例）
  • 安装Node.js
    sudo apt install nodejs
  • 验证安装
    node -v

方法3，使用Node版本管理器NVM安装（推荐）

博主喜欢清爽的环境，因此这里推荐使用NVM安装并管理Node版本。

  • 安装nvm
  • 验证安装
    node -v
    npm -v

    PS: 如果在执行上述nvm ls后没有东西，并且后续安装node提示找不到，可以执行下列命令。

2. 安装Git以及Hexo-cli

步骤一，安装Git

Git是一种分布式版本控制系统，跟踪文件变化，协助多人开发项目，有效管理代码版本。安装Git直接通过apt包管理工具就可以，当然也可以上官网自行下载最新release版本，这里不再详解。
sudo apt-get install git

步骤二，hexo-cli安装

hexo-cli就是封装了命令行的hexo程序包，一般安装hexo-cli即可完整管理博客。
npm install -g hexo-cli
要注意换源，否则下载速度很慢，注意淘宝最新的镜像源如下：
npm config set registry https://registry.npmmirror.com
换完源后，可以考虑安装淘宝命令工具cnpm：
npm install -g cnpm --registry=https://registry.npmmirror.com
之后就可以使用cnpm来进行包安装和管理了，相比于直接国内直接使用npm，速度上有很大优势。
安装完hexo-cli后，执行下列命令验证：
hexo version

PS: 国内npm镜像源还有如下：
腾讯:http://mirrors.cloud.tencent.com/npm/
华为：https://mirrors.huaweicloud.com/repository/npm/
中科大镜像:https://registry.npmjs.org/

三、Hexo框架博客搭建

Hexo的基本命令可以参考手册：文档 | Hexo，下面一起走一遍基本流程。

步骤一，初始化博客文件夹

  • 创建文件夹
    mkdir myblog
  • Hexo初始化文件夹
    hexo init myblog
  • 安装依赖
    cd myblog
    npm install

步骤二，编辑配置文件，并进行初步测试

  • 编辑配置文件_config.yml
    vi _config.yml

  • 编译文件
    hexo g

  • 部署博客
    hexo d

  • 博客”上线“
    hexo server -p your_port

    这里说明下，your_port替换成你的端口，对于服务器端口来说，一般范围在1到65535，但有些约定俗成的协议，即针对特定的服务开放专用的端口，这里可以参考下文章：常用端口及范围。

这里考虑到刚申请的域名还未完成ICP备案，因此无法直接开放访问80端口，因此为了测试网站效果在服务器安全组开放了8080端口作暂时测试，此时要指定your_port为8080才能正常访问。

到这一步，已经基本完成了云服务器上Hexo博客的初步搭建，访问网站可以看到Hexo的欢迎页，接下来对博客作初步的美化设计，这里推荐Hexo-Fluid主题，也是博主认为相对优雅且功能完备的一套主题。

步骤三，更换主题至Hexo-Fluid

这一步可以直接参考：开始使用 | Hexo Fluid 用户手册 (fluid-dev.com)即可，Fluid用户手册写的十分详细，且安装好后基础的配置教程也在这里。下面以Github克隆仓库到本地的部署方式为例，简要介绍下注意事项。

  1. 在博客根目录下，执行克隆主题仓库到本地操作
    git clone https://github.com/fluid-dev/hexo-theme-fluid.git theme/fluid
  2. 将主题中的_config.yml复制一份，并更名为_config.fluid.yml到博客根目录，对于Hexo5.0以上的版本，能够自动识别根目录下_config.xx主题.yml的配置文件，并将其设置为优先级最高，从而调整该文件可视为对主题配置做了调整。
  3. 将博客根目录下_config.yml文件中的theme项，修改为fluid。
  4. 重新执行hexo clean、hexo g、hexo d以及hexo server等命令即完成了主题更换。

    到此位置，个人博客就初具雏形了，鼓掌！！！

步骤四，博客长期运行

也许你会产生疑问，如果一旦退出云服务器链接，那么hexo server命令就会自动终端，从而网站也没办法访问了，有没有解决办法呢？当然有，而且很简单。
pm2是一个管理nodejs process的工具，用简单的指令即可启动nodejs进程，并保证在后台不被杀死。

  • 首先安装pm2
    npm install -g pm2
  • 进入博客根目录，新建文件：run.js
  • 启动进程服务
    pm2 start run.js
    启动后，一般会输出如下结果，即表示成功：
  • 结束进程服务
    pm2 stop run.js

    此外还有很多应用方式，各位感兴趣可以自行查看手册快速开始 | PM2中文网 (fenxianglu.cn)。

四、小结

教程进行到这里基本算完成了，后面如果做一些博客个人化定制、美化工作，可能会继续更一些该主题美化的教程，也或者是干脆分享一些比较好的美化教程链接供大家参考。最后希望各位能从这篇博客里学到一些东西，如果能帮助到你，那我觉得太棒了。
