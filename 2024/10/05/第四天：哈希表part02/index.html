383. 赎金信

力扣题目链接(opens new window)

给定一个赎金信 (ransom) 字符串和一个杂志(magazine)字符串，判断第一个字符串 ransom 能不能由第二个字符串 magazines 里面的字符构成。如果可以构成，返回 true ；否则返回 false。

(题目说明：为了不暴露赎金信字迹，要从杂志上搜索各个需要的字母，组成单词来表达意思。杂志字符串中的每个字符只能在赎金信字符串中使用一次。)

思路： 这题跟242.有效的字母异位词比较像，只是不需要管magazine中的字符能不能由ransom字符组成，也就是单方面的判断即可。代码中体现出来就是，对于字母异位词判断，必须要求哈希表中所有值都是0，而本题只需要保证不存在负数即可。

202. 快乐数

力扣题目链接
编写一个算法来判断一个数 n 是不是快乐数。

「快乐数」定义为：对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和，然后重复这个过程直到这个数变为 1，也可能是 无限循环 但始终变不到 1。如果 可以变为  1，那么这个数就是快乐数。
如果 n 是快乐数就返回 True ；不是，则返回 False 。

示例：
输入：19
输出：true
解释：
1^2 + 9^2 = 82
8^2 + 2^2 = 68
6^2 + 8^2 = 100
1^2 + 0^2 + 0^2 = 1

思路： 循环计算sum，用一个哈希集合存放sum，如果某次循环检测到sum已经存在，说明出现了无限循环，直接返回false，如果最终sum=1，那么返回true。

【拓展】本题也可以用快慢指针法，当出现循环就等同于出现了环，而判断有无环 快慢指针是最常用的方式。这种写法空间复杂度能到O(1)，而且这个写法比较帅。

1. 两数之和

力扣题目链接(opens new window)

给定一个整数数组 nums 和一个目标值 target，请你在该数组中找出和为目标值的那 两个 整数，并返回他们的数组下标。
你可以假设每种输入只会对应一个答案。但是，数组中同一个元素不能使用两遍。
示例:
给定 nums = [2, 7, 11, 15], target = 9
因为 nums[0] + nums[1] = 2 + 7 = 9
所以返回 [0, 1]

思路： 暴力解法就是两层for循环，时间复杂度O(n^2)。而且这道题可以可以借助哈希表来减少时间复杂度，因为哈希表查询的时间复杂度是O(1)的，借助哈希表，将遍历过的元素 索引和值存放到哈希表中，然后在后面的遍历中，每次询问哈希表中是否存在 target - num，若存在，则返回下标。因为这道题要记录下标，所以用unordered_map，unorderer_set只能存放key，不能存放value。对unordered_map而言，C++中也支持std::map std::multimap std::unordered_map三种，且map和multimap都是底层由红黑树实现的，unordered_map底层由哈希表实现。

454. 四数相加

力扣题目链接

思路： 这题有点像两数之和的升级版。本题当然不可以用四重暴力循环来做，时间复杂度太高，考虑使用哈希表优化查询，首先用一个哈希Map统计A和B中所有元素相加结果的次数，然后在遍历C和D，找到C+D+A+B = 0情况并统计次数，此时哈希表的优势体现出来，当0 - （C+D)在哈希表中存在的话，就直接计数加上哈希表对应的值即可，因为这意味着存在这么多个A+B的组合满足A+B+C+D=0。

15. 三数之和

力扣题目链接(opens new window)

给你一个包含 n 个整数的数组 nums，判断 nums 中是否存在三个元素 a，b，c ，使得 a + b + c = 0 ？请你找出所有满足条件且不重复的三元组。

注意： 答案中不可以包含重复的三元组。
示例：
给定数组 nums = [-1, 0, 1, 2, -1, -4]，
满足要求的三元组集合为： [ [-1, 0, 1], [-1, -1, 2]]

思路： 如果是两数之和，那可以考虑使用哈希表，对于本题而言，需要找到 a b c三个数相加等于0，如果依旧使用哈希表，首先用两层for循环确定两个数值，然后用哈希法确定0 - (a + b)，这当然也是可以的，但考虑到题目中有不可以出现重复三元组的问题，此时再用哈希法来做也很复杂。当然可以把代码贴出来体验一下（哈希+排序）。

事实上，面试常考的三数之和、四数之和用双指针法 + 排序比较好。

18. 四数之和

力扣题目链接(opens new window)

题意：给定一个包含 n 个整数的数组 nums 和一个目标值 target，判断 nums 中是否存在四个元素 a，b，c 和 d ，使得 a + b + c + d 的值与 target 相等？找出所有满足条件且不重复的四元组。

注意：
答案中不可以包含重复的四元组。
示例： 给定数组 nums = [1, 0, -1, 0, -2, 2]，和 target = 0。 满足要求的四元组集合为： [ [-1, 0, 0, 1], [-2, -1, 1, 2], [-2, 0, 0, 2]]

思路： 这题和三数之和完全一致，也用双指针法即可，只是多了一层for循环。
