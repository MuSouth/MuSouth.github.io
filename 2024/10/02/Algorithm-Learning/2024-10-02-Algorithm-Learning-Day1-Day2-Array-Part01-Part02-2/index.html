209. 长度最小子数组

力扣题目链接(opens new window)

给定一个含有 n 个正整数的数组和一个正整数 s ，找出该数组中满足其和 ≥ s 的长度最小的连续子数组，并返回其长度。如果不存在符合条件的子数组，返回 0。

示例：

  • 输入：s = 7, nums = [2,3,1,2,4,3]
  • 输出：2
  • 解释：子数组 [4,3] 是该条件下的长度最小的子数组。

提示：

  • 1 <= target <= 10^9
  • 1 <= nums.length <= 10^5
  • 1 <= nums[i] <= 10^5

思路： 这道题主要暴力解法就是两层for循环，外层循环从0到末尾，内层循环则从外层循环元素起点，往后连续相加求和，找到大于目标值的索引，最后计算子序列长度，不断更新最小子序列长度。但实际上本题重要性在于引入了数组操作中另一个重要方法：滑动窗口。

滑动窗口就是不断调整子序列的起始位置和终止位置，从而得到想要的结果。
暴力解法中用到两个for循环，而滑动窗口一个for循环即可。并且这里注意：for循环一定用来表示滑动窗口的终止位置。

首先确定本题中的窗口属性：

  • 窗口内是什么？ 是子序列元素
  • 如何移动窗口的结束位置？就是遍历数组的指针
  • 如何移动起始位置？如果当前窗口和大于等于给定值了，窗口就该缩小了。
    这里也不需要去考虑说，如果我缩小了，后边不会再有满足条件的子序列怎么办这种问题，因为我们还需要维护一个result，这个result始终在与当前子序列长度比较 并取小值，进而维护了一个始终是最小的长度结果。
    也不用想着说，我们移动了起始位置后，是不是就破坏了大于目标值的情况，这本身就是我们想要的，破坏了原有的大于，转而找新的子序列。仔细学习下面代码中的while块，这里是算法精髓。

59. 螺旋矩阵II

力扣题目链接
给定一个正整数 n，生成一个包含 1 到 n^2 所有元素，元素按顺时针顺序螺旋排列的正方形矩阵。
示例:
输入: 3 输出: [ [ 1, 2, 3 ], [ 8, 9, 4 ], [ 7, 6, 5 ] ]

思路： 属于模拟题，考察对代码的掌控，面试常出。这道题和二分法一样，坚持循环不变量原则，按照规则（左闭右开，或左闭右闭的边界定义）画圈。

上图中，每个颜色表示一个边的，在拐角处让给一个新的一条边来绘制了。这就是坚持了左闭右开的原则，最后中间的元素需要单独处理。这种模拟题就是多写，找找手感就行了，没什么特别的算法思想在里面。
简单来说，既然要模拟螺旋，一圈一圈的去填充，每圈出发点都在对角线上。也就是(start, start)，每圈填完后start + 1即可，然后从每个循环的初始位置出发，填充的值始终是连续加1，直到填充的值等于n* n时结束，填充顺序在每圈循环里都是固定的，从左到右，从上到下，从右到左，从下到上直到start, start坐标前。确定好了每圈起始位置，下面确定边界条件，起始位置已经确定了，每次可以设定终止位置为n - offset，也就是如上图那般，将拐角元素让渡给下一个边的填充过程，这样就能保证每次循环的边界范围固定了。否则考虑第一行填充的时候直接填到n位置，那从上到下的起始位置改变了(start, start + 1)，而且后面整个都乱了。

输出每个指定区间内元素的总和。

输出示例：

这题值得记录是因为 前缀和 是数组算法中重要的一部分，尤其在涉及计算区间和的问题时很有用。假设我们就用暴力的计算方法，就是根据给的每个区间，都去查询区间范围内的值，将值加和起来再返回，时间复杂度是O(n* m)，m是查询次数。可能会超时。因此有一个适用于这类问题的解法即本题分享的前缀和。前向过程走一遍，将从0开始的累加值作为前缀数组的元素。


而当我们想得到某区间内的元素和时，就直接用前缀数组中的值作计算即可。思想很简单，但也确实有点意思。(本题用ACM输入输出模式)

44. 开发商购买土地

44. 开发商购买土地（第五期模拟笔试） (kamacoder.com)
在一个城市区域内，被划分成了n * m个连续的区块，每个区块都拥有不同的权值，代表着其土地价值。目前，有两家开发公司，A 公司和 B 公司，希望购买这个城市区域的土地。 

现在，需要将这个城市区域的所有区块分配给 A 公司和 B 公司。

然而，由于城市规划的限制，只允许将区域按横向或纵向划分成两个子区域，而且每个子区域都必须包含一个或多个区块。 为了确保公平竞争，你需要找到一种分配方式，使得 A 公司和 B 公司各自的子区域内的土地总价值之差最小。 

注意：区块不可再分。

思路： 最暴力的思路就是一个for枚举分割线，两个for分别计算子区间的和，这样时间复杂度O(n^3)，可以考虑使用前缀和的方式，分别求出行前缀和以及列前缀和，从而方便后续分割后区间的和计算。

时间复杂度降到了O(n^2)。
