数组理论基础与基础操作

数据属于最基础的数据结构，这块的题目思维不难，主要是代码细节，例如一些边界条件需要非常清晰才可以。首先数组的定义：数组是存放在内存空间上的相同类型数据的集合。 数组可以通过下标索引快速获取对应下标位置的数据。数组满足以下两点：

  • 数组下标从0开始
  • 数组内存空间地址连续

    对于数组来说常用操作包括：
  • 初始化数组
  • 访问元素
    数组索引从0开始，索引本质上是内存地址的偏移量。
  • 插入元素
    在某个位置插入元素后，需要将之后的元素后移动一位，而且如果数组长度固定，原本数组末尾数字会消失。
  • 删除元素
    删除某个元素后，其之后的元素都往前移动一位。 对数组的查询/删除/插入等都属于最基本的操作，这里不再详细解释。可以看到，虽然数组查询的时间复杂度很低O(1)，但是插入和删除时平均时间复杂度都达到了O(n)，而且数组插入元素时，可能导致超出数组长度的元素丢。
  • 遍历数组
    就是根据索引走一遍数组每个元素
  • 数组扩容
    在复杂系统环境中，难以保证数组之后的内存空间是可用的，因此无法安全的扩展数组容量，因此大多数编程语言中数组容量不可变，一般扩容数组都是重新建立一个更大的数组，然后把原数组的元素依次复制到新数组中，这是O(n)的复杂度，数组大时很慢。 数组的优点不必多言：数组存储在连续空间，元素类型相同，空间效率高，支持随机访问，并且具备缓存局部性，当访问数组元素时，计算机还会加载其周围数据，提升后续操作的执行速度。但数组的缺点也存在：长度不可变，空间可能被浪费，插入和删除时间效率低。

常见数组代码题

704. 二分查找

力扣题目 链接
给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target  ，写一个函数搜索 nums 中的 target，如果目标值存在返回下标，否则返回 -1。

思路：这道题前提是数组有序，而且还没有重复元素，属于最简单的二分查找用法。这里要注意的重点是：二分查找的边界条件设定，到底是while(left < right)还是while(left <= right)，是right = middle，还是right = middle - 1，或者left = middle或left = middle + 1等等。这里要重点搞清一个概念，区间的定义是不变量，二分查找过程要保持不变量。在二分查找过程中，区间定义有两种，一种是全闭，即左闭右闭[left, right]，左闭右开[left,right)。

第一种，左闭右闭

因为这里定义target在[left, right]区间，这就决定了二分法的代码应该如何写，因为定义target在[left, right]区间，所以有如下两点：

  • while (left <= right) 要使用 <= ，因为left == right是有意义的，所以使用 <=
  • if (nums[middle] > target) right 要赋值为 middle - 1，因为当前这个nums[middle]一定不是target，那么接下来要查找的左区间结束下标位置就是 middle - 1

第二种，左闭右开

如果说定义 target 是在一个在左闭右开的区间里，也就是[left, right)。
有如下两点：

  • while (left < right)，这里使用 < ,因为left == right在区间[left, right)是没有意义的
  • if (nums[middle] > target) right 更新为 middle，因为当前nums[middle]不等于target，去左区间继续寻找，而寻找区间是左闭右开区间，所以right更新为middle，即：下一个查询区间不会去比较nums[middle]

27. 移除元素

力扣题目链接
给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素，并返回移除后数组的新长度。不要使用额外的数组空间，你必须仅使用 O(1) 额外空间并原地修改输入数组。
元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。
示例 1: 给定 nums = [3,2,2,3], val = 3, 函数应该返回新的长度 2, 并且 nums 中的前两个元素均为 2。 你不需要考虑数组中超出新长度后面的元素。
示例 2: 给定 nums = [0,1,2,2,3,0,4,2], val = 2, 函数应该返回新的长度 5, 并且 nums 中的前五个元素为 0, 1, 3, 0, 4。

暴力思路：直接两层循环，第一层循环遍历数组，遇到等于val的元素，利用第二层循环更新数组，将该元素后的所有数据往前移动，这个解法复杂度O(n^2)，所以这里了解一个更好的解法，利用双指针（快慢指针）在一个for循环下做两个for的工作。

首先定义快慢指针的含义：
快指针：遍历原数组；
慢指针：新数组下标位置。
当快指针指向的元素是要删除的值时，停止更新慢指针，快指针空走；
当快指针指向的元素不是要删除的值时，快慢指针都往前走，并且时刻把快指针的元素送给慢指针的元素。

977. 有序数组的平方

力扣题目链接(opens new window)

给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。
示例 1：

  • 输入：nums = [-4,-1,0,3,10]
  • 输出：[0,1,9,16,100]
  • 解释：平方后，数组变为 [16,1,0,9,100]，排序后，数组变为 [0,1,9,16,100]

示例 2：

  • 输入：nums = [-7,-3,2,3,11]
  • 输出：[4,9,9,49,121]

思路：先把所有元素更新为平方值，再排序；这种暴力解法O(n + nlogn)的，分别是遍历的时间复杂度和快排的时间复杂度。这道题同样可以考虑双指针，因为数组本身有序，只不过负数平方后可能顺序改变，数组平方的最大值只会在数组两端，不是左边就是右边，不会是中间。

因此这道题用双指针法，定义一个新数组，大小和输入数组一致，让i和j分别从0和数组末尾开始往中间走，比较两个位置元素平方谁大谁就把平方值放到新数组，新数组倒着往前放值

当然这道题也可以用归并的思想来做，首先找到正负数的分界，然后分成的两个子数组分别平方后排序，再分别遍历两个子数组，分别比较两个子数组元素大小，按从小到大顺序依次放到新数组中。
