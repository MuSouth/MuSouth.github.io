LLM推理系列推理框架之vLLM

MuSouth
2025-12-13 (Updated: 2025-12-14)
LLM-Inference
vLLM, 推理

前言

vLLM是一个高性能的大语言模型推理和服务框架，由UC Berkeley开发。它通过PagedAttention技术实现了高效的KV Cache管理，显著提升了推理吞吐量。本文将对vLLM的核心技术和架构进行详细介绍。

2. vLLM源码解读

主要是vllm代码库：
vllm/：

  • Entrypoints (LLM, API server)

  • Engine (同步：llm_engine.py ， 异步：async_llm_engine.py)

  • Core

    • scheduler (step/iteration)
    • block_manager (KV cache manager)
      • Paged Attention (ToRead: LMCache，vllm production stack)
    • evictor
      • prefix caching 非常重要 <— (What if prefix doesn’t match? CacheBlend. What if prefix cache on another machine? KV cache sharing across nodes.)
      • kv cache optimization
        • DeepSeek (MLA)
      • LRU cache （最近最少使用缓存）
        LRU cache基于最近最少使用原则的数据淘汰算法的缓存机制，核心思想是当数据容量达到上限，优先移除哪些最近没有被访问过的数据。LRU实现通常使用双向链表和哈希表，双向链表用于维护数据项的顺序，确保最近使用的数据总是位于链表头部，最久未使用的数据位于链表尾部。哈希表则提供O(1)时间复杂的查找能力。

  • Worker (承接scheduler分配的任务)

  • Model_Executor (Model Runner) （models里都是vllm适配的模型定义）

    • Modelling （模型结构定义代码标准化，把其他模型代码转化为vllm的代码）

  • Attention

    • Backend (各种常用Attention的定义和部分Trition实现)
  • distributed:
    Infra-side:
    • Why distributed inference?
      • Communication Device （硬件）
        • NVLink: GPU之间的物理通信连接
        • Infinity Band: between nodes
        • RDMA (Remote direct memory access)
      • Communication library (软件) distributed/device_communicators/
        这块通信原语学习参考：sys(2): 通信原语及其性能分析 - 知乎 (zhihu.com)
        • pyNCCL : communication for NVIDIA
        • shared memory : os
        • custom all reduce : A kernel just for all reduce operations
          • All reduce
          • All gather
          • Scatter等等
        • torch.distributed

    Algorithm-side:

    • /model_executor/models/llama.py 包含了最正统的并行
    • parallel type : TP PP DP EP
    • PD分离
      周边：
  • Preprocessing / Postprocessing (tokenizer, detokenizer, sampler, multimodal processor)
  • Distributed
  • torch compile
  • Observability
  • Config
  • Testing
  • CI/CD

优化：

  • Speculative decoding
  • Disaggregated prefilling
  • Chunked prefill
  • Cascade inference
  • Prefix caching
