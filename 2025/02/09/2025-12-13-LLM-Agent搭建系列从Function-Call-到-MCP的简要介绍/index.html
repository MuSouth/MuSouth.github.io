【LLM-Agent搭建系列】从Function Call到MCP的简要介绍

LLM-Agent LLM-Agent MCP 2025/02/09

本文于 307 天之前发表，文中内容可能已经过时。

FunctionCall

FunctionCall的核心功能就是让大模型根据用户需求，精准调用外部工具，常见的包括天气查询、调用浏览器搜索、查询数据库等，FunctionCall承载着将自然语言转化为结构化指令的作用，例如用户提问“北京今天多少度？”->模型生成“get_weather(location=“北京””的调用参数等等诸如此类。其技术路径一般为：

  • 注册函数信息：告诉模型有哪些工具可以用（函数名称、调用参数格式等等）
  • 意图识别：大模型根据用户输入，判断是否调用工具，调用什么工具
  • 生成结构化指令或参数：输出符合工具要求的结构化数据（比如json）
  • API调用：精准传递参数并返回数据的过程

Agent

Agent核心功能是自主规划任务流程、调用多个工具完成复杂目标，比如你只给Agent一个指令：写一份十月份去大理的旅游攻略、编写一个贪吃蛇程序等等。Agent会根据目标将任务拆解为多个步骤，进而调用不同工具获取数据完成步骤，其技术路径：

  • 推理能力：大模型分析任务目标，拆解成若干步骤
  • 工具调用：调用FunctionCall执行具体操作（查询天气、查询机票等）
  • 循环迭代：根据工具返回结果修正计划（例如天气不好xxx、当日机票订满了xxx）
  • 典型场景：智能客服、助手等

MCP

Model Context Protocol，模型上下文协议是一种通用开放标准，用于将AI系统和数据源连接起来，用单一协议取代碎片化的集成。这是一种将AI助手连接到数据所在系统（包括内容存储库、业务工具和开发环境等）的新标准，由Anthropic 2024年11.25发布文章所述。
MCP的核心遵循客户端client-服务器server架构，主机应用程序可以连接到多个服务器。

  • MCP Host：希望通过MCP访问数据的Claude Desktop、IDE或其他AI工具等
  • MCP Clients：与服务器保持1：1链接的协议客户端
  • MCP Servers：轻量级程序，每个程序都通过标准化的Model Context Protocol公开特定功能
  • Local Data Sources：MCP服务器可以安全访问计算机的文件、数据库和服务
  • Remote Services：MCP服务器可以连接到的Internet上可用的外部系统（例如API）

MCP作为一种开放协议，标准化了应用程序如何为LLM提高上下文，是AI模型的“万能转换头”。
MCP的技术路径一般为：

  • MCP Client（Claude Desktop / Cursor等）发送问题到LLM
  • LLM分析可用工具，并决定使用哪一个或多个
  • 客户端通过MCP Server执行所选工具
  • 工具执行结果返回给LLM
  • LLM结合执行结果构造最终的prompt并生成自然语言回应
  • 展示给用户最后响应
    并且官方也提供了非常多现成的 MCP Servers，只需要选择你需要接入的工具，然后接入即可。

好用的开源代码

1. FastMCP

FastMCP的优势

FastMCP是MCP协议的高级python实现，简化了创建MCP服务器何客户端的过程，与直接使用底层MCP SDK相比，FastMCP开发高效、简洁、python设计、实现规范。
FastMCP核心包括tool()、prompt()、resouce()等等，具体介绍参考这篇博客，写的比较全面。

2. MCP-LLM-Bridge

大型语言模型（LLM）的应用场景越来越广泛，而不同模型之间的协议差异也带来了集成和使用上的挑战。本文将详细介绍MCP LLM Bridge，这是一个连接Model Context Protocol (MCP)服务器与OpenAI兼容LLM的桥接工具，它使得任何兼容OpenAI API的语言模型都能够通过标准化接口利用MCP兼容工具，无论是使用云端模型还是本地部署的实现（如Ollama）。
MCP LLM Bridge是一个双向协议转换层，在MCP和OpenAI的函数调用接口之间建立联系，它将MCP工具规范转换为OpenAI函数模式，并处理函数调用回到MCP工具执行的映射。这种设计使得开发者可以在不同的模型和工具生态系统之间无缝切换，极大地提高了开发效率和系统灵活性。
具体介绍和使用参考这篇博客。

MCP的定位

很多时候MCP好像与Function Call区别不大，只是它规范了API等工具的调用，所以很多人将其理解为Function Call的集合，实际上MCP的意义可能远大于此。这篇文章写的很好，值得一看。
